# Reference Rules

## Folder Structure

references/

* ui/
* wireframes/
* inspirations/

---

## UI References

Check the `references/ui/` folder for:

* Layout direction
* Overall page structure
* Application flow and navigation paths

*CRITICAL:* Do NOT use this folder for visual aesthetics. Use it strictly to extract structural layout patterns and screen flows.

---

## Wireframes

Check the `references/wireframes/` folder for:

* Detailed screen structure
* Specific card configurations
* Detailed form fields and information hierarchy

*Rule:* Wireframes are the source of truth for structural detail. If a UI reference conflicts with a wireframe, the wireframe structure wins.

---

## Inspirations

Check the `references/inspirations/` folder for:

* Visual aesthetic guidance (color palettes, dark modes, styling feel)
* Micro-interactions and UI state changes
* Component animations and card behaviors
* Overall product thinking and feeling (Perplexity/Linear style)


---

## Design Goal

The final product should feel:

* Clean
* Minimal
* Modern
* Premium
* AI native

Avoid feeling like:

* TradingView
* Zerodha
* Traditional broker dashboards

The product should feel like a research workspace, not a trading terminal.
