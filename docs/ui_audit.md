# UI & UX Audit Report

This document outlines a senior product design and UX audit of the current dashboard implementation of **StalkTheMarket**.

## 1. Summary of Gaps

| Audit Area | Problem Identified | Severity | Recommended Fix | Before/After Rationale |
| :--- | :--- | :--- | :--- | :--- |
| **Data Sync State** | Synced status says "Synced" but no actual data updates occur because mock authentication toggles the client's `mock_mode` to `False`, forcing real API calls that fail with mock credentials. | **Critical** | Keep `mock_mode = True` when authenticated using mock credentials in `verify_mpin`. | **Before:** Confusing interface where sync succeeds but demat holdings are empty/broken.<br>**After:** Synced states immediately display mock demat data, validating the client auth workflow. |
| **Dashboard Balance** | AI Trading Assistant Chatbot has a fixed height (`h-[520px]`), which misaligns with the dynamic left-hand grid section height, causing layout gaps. | **High** | Remove fixed height from `Chatbot.tsx`, set it to `h-full`, and stretch the right grid column to match the left column height. | **Before:** Ragged heights between columns.<br>**After:** Balanced and clean double-column layout where the chatbot aligns perfectly with the adjacent content height. |
| **Market Overview** | Market health, momentum, and volatility widgets occupy too much vertical space with generic boxed cards. | **Medium** | Redesign as a compact "Market Pulse" banner using a modern, unified horizontal card without heavy nested border boxes. | **Before:** Clunky three-card layout taking up 25% of the screen.<br>**After:** Minimalist, high-density banner focusing purely on key metrics. |
| **Opportunities List** | Opportunities feel like rows in a plain table. They lack stock prominence, scannability, and visual cues. | **High** | Transition rows into premium Opportunity Cards with a clear grid layout, prominent score indicator, clear visual action buttons, and beautiful sparklines. | **Before:** Grid of gray, plain text rows that require reading to find details.<br>**After:** High-scan cards where stock details, entry/target pricing, and AI score can be read in under 3 seconds. |
| **Sidebar Navigation** | Sidebar options look template-like, lacking refined active states, consistent branding, and proper visual groupings. | **Medium** | Introduce distinct Indigo-accent active states, clean grouping headers, and a premium logo section with proper spacing. | **Before:** Grayscale links that are difficult to distinguish.<br>**After:** Clean, modern, high-contrast sidebar with strong visual hierarchy. |
| **Typography Scale** | Font weights and hierarchy are inconsistent; elements use custom inline font sizes (like `text-[10px]` and `text-[9px]`) which are unreadable. | **High** | Scale up default Tailwind tokens by 10-15% globally, using clear CSS variables for semantic typographic styles. | **Before:** Tiny, hard-to-read text labels.<br>**After:** Accessible, readable font sizes with a clean hierarchy. |
| **Visual Clutter** | Excess nested borders ("boxes inside boxes inside boxes") create a heavy developer-focused interface. | **Medium** | Reduce border dependencies. Use spacing, background fills, and subtle elevation changes to differentiate cards. | **Before:** Double and triple nested borders outlining every minor stat.<br>**After:** Clean, border-reduced design using surface hierarchy (zinc fills and white cards). |
| **Market Data Widget** | Nifty and Sensex sparklines at the bottom of the sidebar feel detached and disconnected. | **Medium** | Redesign them into a clean "Indices Bar" or style them with rich colors to feel like an intentional part of the system. | **Before:** Dark-bordered list boxes at the bottom.<br>**After:** Sleek, integrated indices sparklines that serve as a real-time monitor. |
| **Component Heights** | Button heights, input paddings, and control metrics vary across the application. | **High** | Establish standard button heights (`h-10` for standard, `h-8` for compact) and standard text sizes for inputs. | **Before:** Action buttons of varying sizing and padding.<br>**After:** Uniform buttons across the order ticket, sync panel, and chatbot input. |
