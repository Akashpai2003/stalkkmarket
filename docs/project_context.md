# Name 

StalkTheMarket

## Vision

StalkTheMarket is an AI-assisted swing trading workspace designed to help traders discover, understand, compare, and track high-probability swing trading opportunities.

The product should feel closer to Perplexity, Linear, and modern AI native software than traditional trading platforms.

The goal is not to overwhelm users with charts and data.

The goal is to surface actionable opportunities and explain them clearly.

---

## Core User Questions

What should I buy?

Why was it selected?

What are the risks?

What is the best opportunity today?

How does this stock compare against another?

Should I wait or enter now?

How does this scrip align with my uploaded trading playbook?

---

## V1 Scope

Focus on:

* Market overview & opportunity discovery
* Stock research & technical analysis
* AI-style summaries and comparative scrip analyses
* Self-training capability based on user-uploaded playbooks/context (PDF/TXT/CSV)
* Secure trade execution (buy/sell placement) via Nubra API
* Basic holdings & funds overview via Nubra API

Avoid:

* Complex portfolio analytics
* Intraday trading
* Options trading
* Futures trading
* Social features
* Paid AI dependencies (utilize local or client-provided APIs)

---

## Data Sources

Primary:

* Yahoo Finance (Historical prices, EOD statistics, scrip information)
* Nubra API (Live holdings, account funds, and live order execution)

Future:

* News feeds
* Sector data
* Market sentiment


---

## Product Philosophy

Signal > Data

Insight > Metrics

Actionability > Complexity

The interface should help users make decisions quickly rather than display every available metric.
