# Stalk Market Project Customization Rules

## Typography & Text Styling
- **NO UPPERCASE / ALL CAPS**: Never use `uppercase` class or `text-transform: uppercase` for normal UI labels, card headers, section titles, chips, buttons, or navigation tabs.
- **Sentence Case Only**: Write all labels, titles, and headers in natural sentence case (e.g. "Potential gain", "Downside risk", "Risk reward", "Entry range", "Holding period", "Technical chart", "Developing setup", "Win rate", "Explore workflows", "Suggested follow-ups", "Popular securities").
- **Ticker Symbols**: Uppercase is ONLY permitted for official stock ticker symbols (e.g. `RELIANCE`, `ICICIBANK`, `TATAMOTORS`, `HFCL`) and established acronyms (`NSE`, `RSI`, `MACD`, `P&L`, `EMA`, `SMA`).
